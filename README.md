# CSET 105 Lecture 6: Objects & OOP

## Lecture Info
This lecture introduces JavaScript objects and object-oriented programming.

## Exercises
1. Create a car object with a make, model, year & color as properties. Add a function within it that starts the car, and prints that it has done so.
2. Create a person object with first name, last name, age & city. Print the full name of the person using both dot & bracket notation. Change the age of the person to 30. Add an occupation to the person. Then, add a method to the person object with a basic greeting, using `this` to refer to the object properties.
3. Create a student object. Its properties contain a name object with first & last property, their age, and the courses they take. Add a method that prints the student's full name & their courses.
4. Write a JSON string representing a laptop, with type & model name. Convert the string to a JS object. Add a price property to the object. Convert it back into a JSON string & print.
5. Create a person class, with name & age properties. Add a method that prints an introduction to the person. Create 2 objects using the class & call the method for each. Then, extend the class by adding a birthday method which increments & prints their new age.
6. Create a bank account class, with owner & balance properties. Add methods that deposit to & withdraw from the account, and displays the current balance. Create an instance from that class & simulate some transactions.
7. Create an animal class, with name & sound properties. Add a method that causes the animal to make a sound, and prints the sound it makes. Create dog & cat objects from the class, and have them make sounds.
